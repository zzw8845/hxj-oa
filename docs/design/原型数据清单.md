# 海峡金 OA 审批系统原型数据清单（纯原型提取版）

> 来源：`docs/design/海峡金OA审批系统原型.html` 内嵌 JS 数据结构。
> 提取方式：脚本按括号配平取出完整数组后逐项解析，本文档不含任何数据库数据或对话衍生内容。
> 整理日期：2026-09-11

## 数据结构与数量

| 数据结构 | 数量 | 说明 |
|---|---|---|
| `const roleConfigs` | 19 个角色 | 每条含：name / department / post / scope / members / permissions |
| `const flowConfigs` | 20 条流程 | 每条含：type / category / nodes |
| `const raw` | 8 条单据 | 首页演示数据 |
| `const departments` | 7 项 | 首页部门下拉演示（另 `pageNames` 内还有一份 roles 8 项演示数组，见 7.2） |
| `const boardStats` | 3 项 | 首页看板装饰数字 |
| `const names` / `people` / `comments` | 7 / 7 / 7 项 | 费用报销泳道图演示（节点名/人物/职责描述），见表 6 |
| `const pageNames` | 8 页 + roles 8 项 | 页面名与演示角色数组，见表 7 |
| `const submitForm` 等表单初始值 | — | 提交/驳回/补材料/加签表单默认值与演示规则，见表 8 |
| `people`（人员演示档案） | 5 条（带工号） | 权限管理-人员页演示数据，与角色体系冲突，见表 9 |
| `const stats` | 3 项 | 个人工作台卡片初始状态（value 全 0，UI 状态非业务数据） |
| 人员花名册 | 40 人 | 由 `roleConfigs[].members` 并集去重推出（纯机械整理，脚本验证） |
| 权限清单 | 40 个 | 由 `roleConfigs[].permissions` 去重推出（纯机械整理） |

> 收录范围说明：以上为原型全部业务相关数据。其余 `const`（homeTemplate、permissionTemplate、cards、flowMenu 等）均为 DOM 元素选择器或页面状态，非数据。
